# 翡翠荘の甘き密室

16人の視点を切り替え、30回の対話と証拠照合でタルト消失の謎を解くHTML推理ゲームの試遊版です。

## 起動

Node.js 24で検証済み。外部パッケージのインストールは不要です。

```sh
npm start
```

起動後、ブラウザで http://127.0.0.1:4175 を開きます。

## 検証

```sh
npm test
```

ゲームと素材は `dist/` にあります。人物は名前のみ表示。具体的なセリフ選択、会話による相性の発見、手帳での証拠照合、任意ヒント、自動保存に対応しています。音は初期OFFです。

目標プレイ時間は1〜2時間ですが、長時間試遊と難易度評価は未実施です。制作資料は収録していません。ブラウザで動くゲームのコードには判定と真相が含まれます。

公開対象は `dist/` のみです。`main` への push 時に GitHub Actions で GitHub Pages へ配置します。

公開先：https://kankan1176.github.io/detective-game-hisuisou/

GitHub の Settings → Pages → Build and deployment → Source は **GitHub Actions** を指定してください。`docs/`・`sources/`、開発用テストは公開物に含めません。

移行元：`kankan1176/game_2`、コミット `3d0559f15f73f7c51a1978643d195945679611c7`。ゲーム本体・素材は変更せず移行しています。

## 画面と操作練習

対話と右側の捜査手帳・人物資料・会話履歴・最終推理を同時に表示します。画面・資料・会話・モーダルはスクロールさせず、「前へ／次へ」のページ切り替えで読み進められます。本文と選択肢は原則16〜19pxです。画面の高さに応じて内容をページに分け、文字を小さくして詰め込まない構成です。

新しい捜査では、人物選択・セリフ選択・会話・証拠照合を体験する操作練習が入ります。練習は本編の30ターン、証拠、信頼に影響しません。完了状態は保存され、既存の進行中データは継続できます。


## 初心者向けガイド

操作練習は15項目です。目的・ページ送り・聞き手・話し相手・話題・セリフ・証拠提示・対話開始・会話の読み方・照合・噂と信頼・人物資料・履歴・最終推理・保存を順番に学べます。「詳しい説明」と「操作場所を表示」で、説明や操作対象を確認できます。

上部の「遊び方」には項目別ガイドと練習のやり直しがあります。再練習を終えると元の本編の進行・選択・会話位置に戻ります。練習では本編のゲーム判定を実行せず、証拠や対話回数を変更しません。
