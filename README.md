# シックスティーン・アンサンブル — 消えた至宝の謎

16人の視点を切り替え、会話・情報共有・記録の照合で進めるブラウザ推理ゲームです。新しい章進行版を実装しています。

## 起動と検証

Node.js 24で検証。外部npmパッケージは不要です。

```sh
npm start
npm test
```

開発サーバーはポート4175。`npm test` は旧版エンジンの回帰検証と、新版の会話・知識・章進行・推理・保存復元を検証します。

Python PlaywrightとChromiumがある環境では、サーバーを起動して実行します。

```sh
python tests/story_ui.py
```

PC・スマホ縦横5サイズで、到着チュートリアルから全6章・結末まで、実際の画面操作で検証します。出力は `/tmp/hisui-story-ui/`。旧UI用の `tests/ui_smoke.py` は旧版の構造を対象とするため、新版には使用しません。

## 新しい進行

- 到着チュートリアル → プロローグ → 全6章 → 無言のエピローグ。
- 各場面の4〜6人から質問役と相手を選択。最終集合では全員に質問できます。
- 回数制限なし。質問役が知らない根拠を使う質問は伏せ、先に共有します。
- 記録側と人物側の両方から知識を確認。記録の閲覧だけで人物に伝わることはありません。
- 必要情報が揃ったらプレイヤーが合流を選択。重要情報の共有後、根拠と結論をボードで照合します。
- 推理は何度でも再試行可能。説明役もプレイヤーが選べます。
- 整理用の時系列ボードでは入手記録を時間帯へ配置できます。配置自体を事実とは扱いません。
- チュートリアル・プロローグ・各章末で自動保存。各区切りを保持し、途中では保存しません。
- タイトルの「つづきから」は直近の保存、「章を選ぶ」は各区切りの保存。途中の章を再プレイしても先の保存は消しません。
- 画面全体はスクロールしません。操作・記録・推理の領域内ではスクロールできます。会話はページ送りに対応。
- 音は初期OFF。動きを減らす設定に対応します。参加者の名前にMBTIや肩書きを付けません。

## 素材と保存

既存17名と追加スタッフ6名の計23名。新素材は `dist/assets/story/`。背景・証拠・エピローグはアトラスの領域を指定して表示します。追加効果音は外部サンプルを使わないオリジナル合成音です。

保存キーは `hisui.chapter-checkpoints.v3`。旧版の保存データは削除せず保持します。旧30ターンの進行と新版の証拠・共有状態は異なるため、自動で完了状態へ変換しません。ブラウザのサイトデータを削除すると保存は消えます。

## シナリオの残課題

新版は到着から結末まで操作できる構成ですが、全候補の所在と共犯の可能性を完全に排除する証拠設計は未完了です。最終ボードは未確認の行動を無実とは判定せず、証拠と本人の説明を照合します。自白前に単独犯が唯一と論証できる完成版とは区別します。第三者による難易度評価・長時間試遊も未実施です。

## 公開

公開対象は `dist/` のみ。`docs/`・`sources/`・制作資料やテストは公開対象に含めません。ブラウザで動くコードには物語と判定が含まれます。

`main`へのpushで既存のGitHub ActionsがGitHub Pagesへ配置します。今回のローカル実装は、pushするまで公開サイトへ反映されません。

既存公開先：https://kankan1176.github.io/detective-game-hisuisou/

移行元は `kankan1176/game_2` の `3d0559f15f73f7c51a1978643d195945679611c7`。旧エンジンと素材は回帰検証・保存保護のため保持しています。新しい入口は `story-data.js`、`story-engine.js`、`story-app.js`、`story.css` です。

## 人物表示の調整と検証

立ち絵は元PNGを維持し、全23名に共通のSVG透過補正を表示時に適用します。薄い半透明の背景跡を落とし、不透明な人物部分を保ちます。画像内の下余白は `sprite-layout.js` に記録し、台詞窓の実際の上端へ人物の下端を合わせます。人物カードにも同じ補正を適用します。

素材を差し替えたときは、画像を編集しない計測ツールを再実行します。

```sh
python tools/measure_sprites.py
python tests/story_alignment.py
```

Pillowは計測用、PlaywrightとChromiumはブラウザ検証用です。6サイズ・全120表情の720配置、会話中の画面回転、短文・長文、20シートの実際のアルファ出力を確認します。

## タイトルの人物演出

PC版は全23名を章構成に縛られない4名ずつの6組に分け（1名は再登場）、約6.5秒ごとに1.6秒のクロスフェードで切り替えます。4名の表示サイズを揃え、左右2名ずつ配置します。人物名だけを表示し、未到達章の章題・証拠・真相は表示しません。停止・再開に対応し、ゲーム開始時に自動切り替えを終了します。動きを減らす設定では自動送りをせず、ボタンで切り替えられます。

スマートフォン版はスタッフを含む全23名の顔中心の肖像と名前を常時表示し、切り替えはありません。縦画面は5列の一覧、横画面はロゴと縦メニューの左右に配置します。画面幅760px以下、または幅1000px以下・高さ500px以下の横画面が対象です。画面回転やウィンドウのサイズ変更でも表示モードとタイマーを切り替えます。

スマホの肖像は `dist/assets/story/ui/faces/` の小さなPNGを使用し、タイトルでは大きな立ち絵アトラスを読み込みません。全23枚で約1.2MBです。元のイラストと会話の立ち絵はそのまま維持します。素材を更新する場合は、開発サーバーを起動し、次を再実行してください。

```sh
python tools/measure_title_faces.py
python tools/build_title_portraits.py
```

前者は頭部の位置を計測し、後者はブラウザで顔の表示領域を192px角の透過PNGとしてキャプチャします。帽子のあるパティシエは顔の表示サイズを優先し、帽子の上部を枠の外に出します。

`python tests/story_title_ui.py` でPCの6組・同一サイズ、スマホ8サイズの全23名・切り替えなし・画像読み込み、メニューとの非重複、画面回転、停止再開、ゲーム開始、動きを減らす設定を検証できます。

## 装飾UI

茶色・薄茶色・薄い黒（チャコール）を共通色に使用。会話窓は不透明な薄茶色、人物名はチャコールの名札、選択肢は濃茶／明るい薄茶色のホバー／茶色の選択状態です。記録・人物・推理・保存・ダイアログ・エピローグも同じ配色で統一しています。タイトルは中央ロゴと、PC・スマートフォンともに中央揃えの縦メニュー（つづきから／はじめから／章を選ぶ）。PC版は同じ大きさの人物4名を左右2名ずつ配置し、6組で切り替わります。スマホ版は全23名の肖像を常時表示します。

共通スタイルは `dist/story.css`、独自に作成した装飾SVGと同梱書体は `dist/assets/story/ui/`。参考画像を切り抜いた素材や透かしは使いません。同梱の明朝体はNoto Serif CJK JPの文字サブセットです。ライセンスは同ディレクトリの `FONT-LICENSE.txt` を参照してください。シナリオに未収録の文字を追加する場合はサブセットも更新してください。

全体スクロールは抑止し、長い会話・記録・推理・ダイアログの中だけをスクロールできます。本文の装飾は読みやすさを優先し、枠内の余白と十分な明暗差を確保しています。

## ワイド画面の表示

PCでは操作欄の幅（360〜640px）をグリッド側で確保し、残りを場面表示に割り当てます。画面の右端に未使用の帯を作りません。会話中の人物は場面幅とセリフ窓までの高さに合わせて拡大し、画面外への横のはみ出しを防ぎます。1600px以上の画面では本文・操作欄の文字とボタンも拡大します。スマホは従来の上下配置とタイトル23名の静止表示を維持します。

`python tests/story_wide_ui.py` は1920×911（ブラウザUIを除いたフルHD画面）・2560×1080・3440×1440など8サイズで、会話・調査・記録・人物・推理・保存・エピローグの収まり、人物の大きさ、長文・改行・操作ボタンを検証します。`tests/story_alignment.py` はワイド画面を含む9サイズ、全120表情の1080配置を検証します。
